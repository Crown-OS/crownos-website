## Quick checks

<AccordionGroup>
  <Accordion title="Is the daemon running?">
    Run `crownpaper ping`. It prints `pong` when the daemon is up.
  </Accordion>
  <Accordion title="Which compositors are supported?">
    Any compositor with `wlr-layer-shell`, `wp_viewporter` and `linux-dmabuf`, such as Hyprland,
    Sway and Niri.
  </Accordion>
  <Accordion title="How do I see more logs?">
    Start the daemon with `RUST_LOG=crownpaper=debug`.
  </Accordion>
</AccordionGroup>
