## Quick answers

<AccordionGroup>
  <Accordion title="Is CrownOS free?">
    Yes. CrownOS is open source and free to download, use and modify.
  </Accordion>
  <Accordion title="Can I install software from the Arch repositories?">
    Yes. CrownOS is based on Arch Linux, so `pacman` and the Arch repositories work as usual.
  </Accordion>
  <Accordion title="Which kernel does CrownOS use?">
    CrownOS ships `linux-cachyos`, the CachyOS kernel with the EEVDF scheduler.
  </Accordion>
</AccordionGroup>
