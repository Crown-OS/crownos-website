CrownOS is an agent native desktop built on the Linux kernel. It starts from CachyOS and Arch Linux,
then replaces the layer you interact with: the compositor, the UI toolkit and the apps that ship with
the desktop.

<Info>
  CrownOS is in public beta. Builds are published on the
  [crownos-iso releases page](https://github.com/Crown-OS/crownos-iso/releases).
</Info>

## What is inside

<CardGroup cols={3}>
  <Card title="Crownpositor" icon="layers">
    A Wayland compositor written in Rust and tuned for low memory, with fully GPU accelerated
    rendering and direct scanout.
  </Card>
  <Card title="CrownUI" icon="sparkles" href="/docs/crownui/introduction">
    The native UI toolkit, rendered by Impeller with shaders compiled ahead of time.
  </Card>
  <Card title="CachyOS kernel" icon="cpu">
    linux-cachyos with the EEVDF scheduler, built with Clang ThinLTO and AutoFDO profiling.
  </Card>
</CardGroup>

## Principles

- **Performance first.** A full desktop that runs in under 1.2 GB of memory.
- **Open source.** Every component is developed in the open under the
  [Crown-OS organisation](https://github.com/Crown-OS).
- **Calm by default.** A monochromatic interface you can reshape through themes, plugins and
  plain-text configuration.
