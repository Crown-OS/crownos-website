<Update label="2026-10-27" description="Beta" tags={["Release"]}>
  ## Highlights

  - The CachyOS kernel (`linux-cachyos`) replaces the stock Arch kernel.
  - Crownpaper 1.0 ships as the wallpaper daemon, with still and video wallpapers.
  - Crown Link pairs phones and tablets for clipboard, notification and file sharing.

  ## Desktop

  - Crownpositor renders with direct scanout so an idle frame costs almost nothing.
  - System apps are built with CrownUI.

  <Note>
    Report problems on the [crownos-iso issue tracker](https://github.com/Crown-OS/crownos-iso/issues).
  </Note>
</Update>
