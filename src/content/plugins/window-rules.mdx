Window Rules lets the compositor remember your layout. Match windows by app, title or role and pin them to a workspace, a monitor or a tiling slot.

## Example

```ron
(
  rules: [
    (app: "org.mozilla.firefox", workspace: 2, tile: Left),
    (app: "com.spotify.Client", monitor: "DP-2", floating: true),
  ],
)
```

Rules reload live as you save the file, no logout needed.
